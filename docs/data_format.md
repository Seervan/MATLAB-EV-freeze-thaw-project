# EV Freeze-Thaw Project – Data Format Notes

## Raw Data (`data/raw/`)

Raw measurement files should be placed here as `.mat` files.  
Each file must contain a MATLAB struct array named `measurements` with the following fields:

| Field   | Type          | Description                                      |
|---------|---------------|--------------------------------------------------|
| `pre`   | `N × 3` double | 3-D point cloud measured **before** freeze-thaw |
| `post`  | `N × 3` double | 3-D point cloud measured **after** freeze-thaw  |
| `label` | `char`        | Sample identifier string                         |

> **Note:** Raw data files are excluded from version control via `.gitignore`.  
> Store them on a shared drive or data repository and document the location here.

## Processed Data (`data/processed/`)

Processed outputs (shape descriptors, summary statistics) are also excluded  
from version control. They are generated by the MATLAB scripts and can be  
regenerated at any time by running `run_shape_analysis.m`.

## Results (`results/`)

Generated figures and report files are also excluded from version control.  
To reproduce them, run `run_post_processing.m` after `run_shape_analysis.m`.

## Python CSV / JSON Export

To use the Python detection script, export shape descriptors from MATLAB as a CSV:

```matlab
T = struct2table(descriptors);
T = T(:, {'label', 'displacement', 'volume_change'});
writetable(T, 'data/processed/shape_descriptors.csv');
```

Then run:

```bash
python python/detection/detect_stiffness_change.py \
    --input data/processed/shape_descriptors.csv
```
